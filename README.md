# 品客小镇·青创城 — 品牌官网

深圳龙华 · 深圳北站未来商务区 · 甲级创客办公园区品牌展示站。
深色高端科技商务风，纯 HTML/CSS/JS 零依赖，配套 SEO / GEO 获客设计。

## 文件结构

```
pinke-innopark/
├── index.html     # 单页长滚动结构（语义化 + SEO/OG + JSON-LD 结构化数据）
├── styles.css     # 深色 + teal→blue 主题、完整响应式
├── script.js      # 导航/动画/计数 + 高德地图 + 留资表单
├── robots.txt     # 搜索引擎与 AI 爬虫规则
├── sitemap.xml    # 站点地图
├── llms.txt       # 给 AI 的园区信息摘要（GEO，利于被 ChatGPT/豆包等引用）
└── assets/        # logo、园区效果图、办公室实景（来自公众号）
```

## ⚠️ 上线前需你补充 / 配置的 4 处

1. **微信二维码**：把招商微信二维码图片存为 `assets/qrcode.png` 即可自动显示（当前是占位提示）。
2. **高德地图**：到 https://lbs.amap.com 申请免费「Web端 JS API」key，填入 `script.js` 顶部
   `AMAP_KEY`（2021 年后申请的 key 还需填 `AMAP_SECURITY`）。未配置时地图区显示带「高德导航」按钮的占位卡，不影响使用。
   园区经纬度 `PARK_LNGLAT` 建议用 https://lbs.amap.com/tools/picker 拾取后校准。
3. **留资表单后端**：`script.js` 的 `leadForm` 提交目前只做前端成功反馈。要真正收到线索，
   接一个表单服务（如金数据 / 问卷星 / formsubmit.co）或你的接口，位置见代码 `TODO 接入后端`。
4. **域名**：`index.html` 里的 `https://www.pinke-innocity.com/`（canonical / og / sitemap / robots）
   换成你的真实域名。

## 获客设计说明（SEO / GEO / 转化 / 裂变）

- **SEO**：标题正文埋词「龙华民治办公室出租 / 深圳北站写字楼 / 可注册公司 / 拎包办公」；
  `LocalBusiness` JSON-LD（地址、电话、经纬度）；图片 alt、sitemap、robots。
- **GEO**：FAQ 用真实问句 + 事实清单作答，`FAQPage` 结构化数据 + `llms.txt`，便于 AI 抽取引用。
- **直接转化**：唯一招商热线 136-1283-2188 全站高曝光、一键拨号、右下浮动按钮。
- **裂变**：老带新奖励板块 + 微信二维码进群 + 留资表单，沉淀电商群与上门流量。
